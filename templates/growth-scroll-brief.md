# CasualSites — Growth Scroll Brief

Use this when the site should feel like it is **growing, progressing, unfolding, or building momentum** as the user scrolls.

## Desired feeling
The experience should begin restrained, then gradually become more alive, more layered, more expansive, and more confident.

## Core motion idea
As the user scrolls:
- lines can extend
- paths can branch
- shapes can scale outward
- scenes can open from narrow to wide
- type can grow in authority
- percentages, counters, or stages can advance
- color can intensify
- elements can accumulate in a controlled way
- the final section can feel like a completed form of what the intro hinted at

## Recommended page arc
### 1. Sparse opening
Very few elements.
A strong headline.
One visual signal.
A sense that something is about to build.

### 2. First activation
A path, object, symbol, percentage, milestone marker, or visual system begins moving or revealing itself.

### 3. Structured progression
Introduce milestones, stages, chapters, values, features, or outcomes as if they are part of one unfolding system.
Avoid disconnected section jumps.

### 4. Expansion moment
The composition should widen, brighten, multiply, or fully assemble.
This is where the site feels like it has truly grown.

### 5. Controlled payoff
Bring things back into clarity.
Use a cleaner layout and stronger CTA to close.

## Motion recommendations
- scroll-linked SVG path drawing
- pinned storytelling section with internal stage changes
- scale-from-center or expand-frame transitions
- staggered type reveals with masking
- density increase across sections
- restrained parallax with depth layers
- section palette shift from quiet to energized
- progress states that visibly advance while scrolling

## Avoid
- random floating decorative elements
- disconnected animations with no shared logic
- a feature-grid section that interrupts the story
- too many competing accents
- fake cool motion that adds no directional meaning
