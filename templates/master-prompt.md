## Creative direction
The website must feel like:
- smooth scroll storytelling
- visual progression / growth
- strong typography
- staged section reveals
- premium art direction
- minimal but deliberate UI

## Explicit inspiration
Use the following qualities as inspiration, not as something to copy 1:1:
- immersive scroll-led storytelling
- sections that transform while scrolling
- bold editorial composition
- minimal nav and high visual confidence
- transitions that make the site feel like it is unfolding
- product polish with strong restraint
- clear state changes instead of stacked blocks

## Hard bans
Do not generate:
- generic startup hero layouts
- repeated feature cards
- bland icon rows
- fake testimonial sections
- overused gradient blob aesthetics
- repetitive fade-up animations
- template-like SaaS page structure
- fluffy explanation before doing the work

## Required build behavior
You must:
1. define the creative direction first
2. outline the scroll story section by section
3. list the major animation systems before coding
4. build at least one major progression section where the site visibly evolves with scroll
5. use typography as a primary design element
6. keep the code clean and editable
7. include reduced-motion handling
8. make the desktop and mobile experiences both intentional
9. keep commentary brief and spend effort on implementation

## Scroll story requirement
The page should feel like it grows, progresses, unfolds, or transforms as the user scrolls.
The motion must feel structural, not decorative.

## Deliverables
- design direction summary
- section-by-section blueprint
- implementation plan
- final code
- short self-critique against the anti-generic checklist
