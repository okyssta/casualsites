# CasualSites — Site Blueprint

Use this blueprint before writing code.

## 1. Core thesis
What is the one-line emotional or strategic thesis of the site?

## 2. Atmosphere
- background world
- dominant mood
- motion intensity
- spatial feeling
- texture / finish

## 3. Typography system
- display size logic
- body size logic
- labels / captions
- uppercase / lowercase behavior
- density of copy

## 4. Scroll narrative
### Scene 1 — Entry
What does the user see first?

### Scene 2 — Discovery
What begins to reveal itself?

### Scene 3 — Progression
What visibly grows, changes, or evolves?

### Scene 4 — Peak
What is the highest-impact moment?

### Scene 5 — Resolution
How does the site calm down and convert?

## 5. Animation systems
List exact systems:
- pinned section
- parallax layers
- masked text reveal
- object scale transform
- timeline or path progression
- percentage / stage advancement
- section color shift
- card stack / unstack
- hover interactions

## 6. Mobile interpretation
What gets simplified, shortened, or restaged on mobile?

## 7. Anti-generic review
What parts risk looking template-like, and how will you avoid that?

## 8. Token discipline
What can be explained in one line instead of five?
