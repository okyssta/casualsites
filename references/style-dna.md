# CasualSites — Style DNA

This file distills the shared visual grammar from the current reference pool.

## Shared traits

### 1. Scroll changes state
The page should evolve as the user moves.
Not just reveal more sections.
Think progression, milestones, path-building, world expansion, and density shifts.

### 2. Typography carries authority
Large display type, sharp subheads, tiny labels, and clear hierarchy do a lot of the heavy lifting.

### 3. Premium restraint beats visual spam
Less clutter.
Fewer ideas per section.
Stronger framing.
Cleaner endings.

### 4. Product polish can coexist with atmosphere
The site can feel high-end and conversion-capable without collapsing into standard SaaS composition.

### 5. Atmosphere matters
The best references feel like they belong to a world.
Lighting, spacing, pace, and transitions create identity.

### 6. Motion has logic
Animation should follow a system:
- path grows
- crop expands
- object progresses
- scene reframes
- density increases
- state advances

### 7. Copy should have a point of view
Fewer safe corporate phrases.
More confidence.
More authored tone.

## Implementation interpretation

When in doubt:
- reduce UI chrome
- increase typographic contrast
- create one truly memorable transformation section
- make the closing feel earned
- keep the narration short and spend time on the build
