# CasualSites — Trigger Queries

These are sample prompts that **should** trigger CasualSites.

- make me a smooth animated landing page that feels premium
- build a cinematic scroll website for my agency
- create a website like x.ai but more unique
- i want a non-generic website with strong motion
- make the site feel like it grows as i scroll
- build an immersive storytelling portfolio
- create a handcrafted landing page with scroll progression
- make a premium product website with smooth section transitions
- i want a site that unfolds as you scroll
- build me a brand site with bold typography and subtle but elite animations

These prompts **should not** be the main target:

- make a plain admin dashboard
- create a CRUD app
- build a documentation site with no heavy motion
- make a basic pricing page only
