# CasualSites

CasualSites is a website-design skill for coding agents that pushes premium, scroll-led, high-art-direction web experiences instead of generic AI-generated landing pages.

**Author:** Kyssta  
**GitHub:** https://github.com/kyssta-exe/

## Trigger

CasualSites is primarily triggered by the **`description` field in `SKILL.md`**. The current trigger language is tuned for prompts about:

- animated websites
- smooth scroll storytelling
- immersive landing pages
- cinematic websites
- premium portfolios
- non-generic brand sites
- growth/progression on scroll
- x.ai-style restraint
- handcrafted, art-directed web experiences

## What it does

- pushes agents toward cinematic, smooth, progression-based websites
- bans generic startup layouts and repetitive card spam
- defines motion grammar for scroll narratives, pinned scenes, reveals, transforms, and staged pacing
- gives implementation rules for HTML/CSS/JS, React, or Webflow-custom-code style builds
- enforces accessibility and performance constraints so motion still feels premium
- includes a reusable master skill file, prompt template, and quality checklist
- favors action-first output with less filler and more implementation

## Included files

- `SKILL.md` — the main skill instructions for agents
- `templates/master-prompt.md` — reusable prompt template for a project brief
- `templates/site-blueprint.md` — structure for planning a premium scroll site
- `templates/growth-scroll-brief.md` — dedicated brief for growth/progression websites
- `examples/animation-patterns.md` — premium motion patterns to use
- `examples/anti-generic-checklist.md` — quick rejection checklist for bland outputs
- `examples/trigger-queries.md` — prompts that should activate the skill
- `references/style-dna.md` — distilled traits from reference sites
